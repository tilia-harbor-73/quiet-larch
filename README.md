# NewGen

Внутрішній застосунок для обліку замовлень і задач невеликої команди.

- Статичний сайт без збирання: HTML, CSS і JavaScript.
- Вхід — через Google; дані зберігаються в базі Firebase і доступні лише учасникам команди. У коді даних немає.
- Працює на комп’ютері й телефоні; сайт можна додати на головний екран як застосунок.

Іконки інтерфейсу — [Lucide](https://lucide.dev) (ліцензія ISC). Шрифти — IBM Plex (SIL Open Font License).
